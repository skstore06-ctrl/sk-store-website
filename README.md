# SK STORE V1

This is a frontend MVP for SK STORE. It includes:
- Store homepage
- Product listing
- Size-wise stock display
- Cart
- Coupon demo (SK20)
- Customer login demo
- Creator Club login demo
- Admin panel demo
- Add product + stock

## Make it fully live for free

1. Create a Supabase project.
2. Create tables for products, product_sizes, users, orders, order_items, coupons, creators, creator_codes.
3. Put Supabase URL and anon key into the app.
4. Replace demo login/order functions with Supabase Auth + database calls.
5. Deploy this Vite project to Cloudflare Pages.

The current project intentionally runs without credentials, so it can be previewed immediately.
